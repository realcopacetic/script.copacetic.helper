### Documentation
---
Guides for skinners who want to use the helper in their own skin:

- [Builder system](resources/docs/builders/00-quickstart.md) — generate includes, variables and expressions from JSON templates, with in-skin settings editors.
- [Plugin paths](resources/docs/plugins/plugin_helpers.md) — `plugin://script.copacetic.helper/?info=…` for container `<content>`.
- [Script actions](resources/docs/script/actions.md) — `RunScript(script.copacetic.helper,action=…)` for action lists.
- [Background service](resources/docs/service/index.md) — what the helper does on its own, and the window properties it sets.
